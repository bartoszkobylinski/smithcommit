# smithcommit

**LLM-Powered Commit Message Generator**

smithcommit is a lightweight tool that analyzes your local Git diffs and uses a large language model (LLM) to generate clear, context-aware commit messages automatically.

---

## Features

- Scans staged changes and summarizes code modifications  
- Integrates with OpenAI (or other LLMs) for natural-language generation  
- Provides editable suggestions before committing  
- Supports custom prompts and configuration  
- Works from the command line in any Git repository  

## Requirements

- Python 3.8 or higher  
- Git installed and available on your PATH  
- An API key for OpenAI (or another compatible LLM provider)
